# Naturia — A World, Naturally Free

An independent, non-sexual, illustrated international naturism guide, in English.

## Features

- Anime-inspired, artwork-only homepage and responsive layout
- Interactive SVG world atlas with coastlines, countries, beaches and resorts
- 35 country guides and 22 location listings
- History, naturist etiquette, topless/topfree guide, signage and laws
- Editorial sources and correction guidance
- No people photography, tracking, advertisements or cookies

**Editorial review date:** 6 November 2026. Legal and local access rules may change. Country listings include both researched and starter-level guides; no visitor reviews are fabricated.

## Publication

This repository is intended for GitHub Pages at:

https://xuthar.github.io/naturia-world/

To enable publishing from this independent repository, select **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**, then save. Any subsequent changes pushed to main will be deployed automatically.

No build or install step is needed. Open `index.html` locally to preview. All page links are hash routes and all assets use relative paths, making the site work on GitHub Pages under a project subpath.

## Repository contents

- `index.html` — shell and SEO meta tags
- `styles.css` — responsive visuals
- `app.js`, `data.js`, `worldmap.js` — navigation, researched content and interactive atlas
- `assets/anime-coast.webp` — original AI-generated anime illustration
- `assets/favicon.svg` — identity mark
- `.nojekyll` — static hosting compatibility

The original Naturia directory is temporarily also hosted under Remembering Sea; retire or redirect that copy only after this repository is public and the new GitHub Pages URL is live.
